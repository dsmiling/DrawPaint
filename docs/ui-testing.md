## 用自己的素材测试

1. 导入效果图，或在组件上选择“拆分”。
2. 审阅拆解范围、类型、完整文字和父层。选择“Mask 边界参考 · AI 完整生成”，点击“生成边界参考”。
3. 在“标注图层边界参考”中查看原图＋标注，用画笔标记目标、排除干扰，填写本层生成要求，然后保存。无需逐像素描边。
4. 点击“使用参考生成完整图层”。AI 先检查已有素材并复用匹配层，仅对缺失或不匹配的图层生图；父底板去掉独立前景并补全材质。
5. 生成完成后逐层检查文字、风格、比例、完整轮廓、镂空和半透明边缘。切换深浅底色、原始分辨率及整体回拼。不满意可返回“调整参考 / 重新生成”。
6. 满意后点击“确认图层并回填画布”，再使用 PSD 或 Unity 导出。PSD 可选 1×、2×、4×；Unity PNG 保留素材分辨率，布局由 RectTransform 表达。

- 真实样例 4× PSD 为 1048 × 324，重新读取四层并逐像素核对坐标及导出结果；Unity ZIP 中四张 PNG 的原生尺寸和逻辑布局分别核对通过。

高清重建仍可能改变字形、边框粗细、颜色或材质。验收以原图和独立图层的视觉对照为准，回拼变化比例不是准确率。文字默认是图片，不代表恢复了原始字体源文件。本轮已核验 Unity 包内容，未在具体 Unity 工程编译导入器。

历史“验收示例 · 原图分割计数器”使用原来的像素提取方案；新流程默认使用参考模式。历史待处理任务可在 Mask 用途中切换。

若本机网页服务停止，在项目目录执行 `npm run dev`。若显示 Agent 待连接，在 Codex 当前任务中启动 `node scripts/ui-agent-bridge.mjs`；无需配置生图 API Key。
