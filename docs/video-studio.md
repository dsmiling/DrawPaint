# 视频工坊

视频工坊把本机图生视频、片段管理、逐帧检查和时间线剪辑放在同一页。运行 `npm run dev` 后，打开 <http://127.0.0.1:43217/?mode=video>。绘画画布中的“选中图片生视频”可以把选中的图片带到视频工坊。

## 运行环境

- DrawPaint 前端与 API，默认端口分别为 `43217` 和 `43218`。
- 本机 ComfyUI，地址为 `http://127.0.0.1:8188`。将 `ComfyUI/` 放在 DrawPaint 项目或数据目录的同级目录，以便检查权重和读取输出素材。
- FFmpeg 和 FFprobe，需要能从服务进程的 PATH 调用；视频导入、逐帧取图和 MP4 导出依赖它们。
- Windows 下，如果同级目录存在 `start_comfy.ps1`，模型设置页可调用它启动 ComfyUI；其他情况请自行启动 ComfyUI。页面不会下载模型或安装节点。

生成视频使用本机 ComfyUI；普通视频操作无需 Codex 连接器或图片 API Key。画布原有的 Codex 生图功能仍按 README 启动连接器。

## 模型准备

“模型设置”会检查连接、模型权重和 ComfyUI 节点。文件位置均相对于 `ComfyUI/models/`。

MiniMax H3 支持起始图、可选尾帧，以及 2、3、5 秒视频，需要：

- `diffusion_models/minimax_h3_fl2va_pruned_fp8_scaled.safetensors`
- `text_encoders/qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors`
- `vae/minimax_h3_video_vae_fp16.safetensors`
- `vae/minimax_h3_audio_vae_fp32.safetensors`
- `loras/minimax_h3_fl2v_turbo_8step_v1.0_comfyui_bf16.safetensors`

Wan 2.2 5B 当前工作流支持单张起始图和 2 秒视频，需要：

- `diffusion_models/wan2.2_ti2v_5B_fp16.safetensors`
- `text_encoders/umt5_xxl_fp8_e4m3fn_scaled.safetensors`
- `vae/wan2.2_vae.safetensors`

具体节点需求在 `server/video-models.mjs` 中定义；MiniMax H3 工作流还使用 `server/video-template.json` 中的节点。模型状态检查通过后，如生成时报缺少节点，需按对应工作流补齐本机 ComfyUI 环境。

## 生成、检查与剪辑

左上角工作模式和视频工坊常用操作使用图标按钮，悬停显示名称与快捷键。节点以缩略图为主，单独选中一个节点后循环预览，取消选中或多选时恢复静态缩略图；节点保留轨道、时长、速度和自定义名称。

1. 点击顶部或左侧“新建片段”图标，也可在空画布点击“＋ 新建视频片段”、双击空白处，或右键选择“新建视频片段”。这会立即建立可保存的草稿节点，并打开右侧“选中详情”。在右侧选择正常视频或帧动画视频、上传首帧、填写动作描述、选择模型与时长，然后点击“生成正常视频”或“生成帧动画视频”。MiniMax H3 可同时使用尾帧图，并根据首帧选择最接近的受支持宽高比。生成结果填入原节点，草稿未生成前也能保存、复制和继续编辑。
2. 左侧“画布片段”支持搜索、用途筛选、显隐和锁定。“视频素材”以预览卡片显示生成记录与已导入视频，顶部仅显示数量和刷新图标。点击选中素材，右键可循环预览或添加到任意画布；选中未锁定草稿时，菜单还可将素材填入该节点。导入支持 MP4、WebM、MOV，每个文件不超过 90 MB；也可拖入视频，或拖入图片建立带首帧的草稿。视频的真实时长、帧率和尺寸由 FFprobe 读取。
3. 中间“节点画布”提供选择、框选、平移、吸附、缩放、适应和整理节点。Ctrl / Shift 点击多选，可一起移动、复制或更改轨道；空格拖动或选择平移工具移动视图，Alt 拖动暂时关闭吸附。左侧、画布和时间线的选中状态同步，右侧显示所选片段属性。
4. 右侧将名称编辑和动画检查合并在同一个区域，名称可在预览上方直接修改。选中片段右键“片段设置”可修改时间线起点、V1–V8 轨道、裁剪起止、0.25–4 倍播放速度、音量、静音、显隐与锁定；窗口中的“画布节点位置与尺寸”默认折叠，展开后可调整节点布局。复制、分割、替换、导出、移除等操作也在右键菜单中；多选后可批量复制、整理、锁定、显隐或移除。时间线可拖动移动、换轨和裁剪，并在播放头处分割。隐藏片段跳过时间线预览和整条时间线导出；锁定片段不能移动、裁剪或移除，但仍可复制。节点位置仅用于整理工作台，不改变最终视频的位置与大小。
5. 右侧“简略 / 完整”检查面板可逐帧选择首尾帧，再用两帧生成新片段。原片段会保留，方便比较。
   简略模式显示当前所选首尾帧范围的动画预览，点击画面循环播放，再次点击暂停；尾帧也包含在播放范围中。修改首尾帧后，预览立即更新并回到新的首帧。完整模式保留首尾帧图片和逐帧选取工具。
6. 切换中间“时间线预览”检查合成结果，播放时执行裁剪、速度、轨道层级、音量和静音设置。选择输出画幅后点击“导出视频”，输出按 24 fps 编码，音频跟随速度并混合；不同宽高比以黑边保持完整画面。整条时间线跳过草稿和未完成片段，单片段导出使用该片段的裁剪、速度和静音设置。
7. 在片段检查中点击“生成透明帧动画”，默认使用当前首尾帧范围（包含完整尾帧）并剔除背景。顶部“导出序列帧”和右键菜单也可进入设置，选择当前首尾帧、当前裁切片段或整条时间线，以及 6–60 fps、PNG / 无损 WebP、单帧最长边和循环播放。单片段保留原始画幅，时间线使用项目画幅、轨道层级和空白间隔；不包含音频。
8. 勾选“剔除背景（透明通道）”，选择自动检测、预设纯色或自选背景色，也可直接点击原帧背景取色。右侧显示原帧和透明效果对比；颜色容差与边缘过渡立即生效。“从外部移除”保护内部同色细节，“移除全部同色区域”可剔除空心区域。点击“生成并预览”后逐帧处理，再自动播放结果；可调整参数重新生成。

生成图片和视频仍需人工检查身份、服装、手部、动作及过渡。提交生成任务成功不代表画面已经通过验收。

编辑操作支持工具栏撤销 / 重做、Ctrl+Z / Ctrl+Shift+Z、Ctrl+D 复制、Ctrl+C / Ctrl+V 在当前工坊的不同画布间复制粘贴、Delete 移除、Ctrl+A 全选和方向键微调节点。也可右键片段选择“复制到剪贴板”，切换画布后在空白处右键“粘贴片段”。拖动作为一次撤销；锁定的节点跳过批量移动与移除。撤销历史保留最近 80 步，只在本次画布编辑会话中有效，刷新或切换画布后清空；保存的片段和关键帧继续保留。

## 视频素材目录

视频素材库由当前项目的所有视频画布共享，支持最多 12 层、200 个文件夹。首次打开会将已有生成视频分别归入“生成视频 / 正常视频”和“生成视频 / 帧动画视频”，导入文件归入“导入视频”。“全部素材”汇总所有目录；选择具体文件夹时，显示其中的直接子文件夹和素材，路径栏可返回上级。

- 点击文件夹加号图标，在当前目录新建文件夹；右键文件夹可新建子文件夹、重命名、移动或移除空文件夹。含素材或子目录的文件夹不能直接移除。
- 点击素材选中，Ctrl / Shift 点击多选。右键可重命名单个素材、将所选素材移动到目标目录，或添加到当前画布。选中未锁定草稿时还可填入该节点。
- 将素材拖到目录树中的文件夹可归档，将文件夹拖到另一文件夹可调整层级。将素材拖到中间画布会创建视频片段；将外部视频文件拖到文件夹会导入该目录。
- 素材库中选择具体目录后，生成或导入的视频归入该目录；从“全部素材”或画布片段面板生成、导入时，按默认来源与用途归档。刷新或重新启动后保留目录归属，切换视频画布继续共享。

资源存储职责如下，均相对于项目的 `canvas/` 目录。文件夹和素材名称、归属只修改 `video-library.json`，原视频使用稳定来源 ID 存储，已有画布的剪辑和导出引用继续有效。显示名称的修改不会覆盖已有画布中的片段名称。

| 路径 | 内容 |
| --- | --- |
| `video-library.json` | 素材文件夹树、视频的目录归属和显示名称 |
| `video-generated/` | 按任务 ID 缓存的模型原视频、固定底色视频和处理记录 |
| `video-assets/`、`video-assets.json` | 导入视频原文件及媒体信息 |
| `video-jobs.json`、`video-job-options.json` | 生成任务及用途、提示词记录 |
| `video-canvases/` | 各画布的时间线、裁剪与视图设置 |
| `video-reference-images/` | 生成使用的首尾参考图 |
| `video-exports/`、`video-exports.json` | MP4、透明帧动画 ZIP 和预览输出 |

## 两种生成用途

新建片段和首尾帧检查面板提供六个“帧动画动作模板”：待机呼吸、原地行走、原地跑步、单次攻击、受击恢复、原地跳跃。选择模板会填入可编辑的动作阶段描述、启用帧动画用途并设置建议生成时长。朝向沿用首帧；行走和跑步保持原地。待机建议 8 fps，其他动作建议 12 fps；前三种用于循环，后三种用于单次播放。保留模板描述的片段，导出窗口会预选建议帧率和循环设置。

像素素材导出支持 64 / 128 px 最长边和“像素（最近邻）”缩放；抠图后再缩放，预览使用同一缩放选择。需要硬边时将边缘过渡设为 0，并勾选“硬边透明（像素素材）”，清除不透明度低于 50% 的残点，其余设为完全不透明；柔光和半透明细节会变为硬边。最近邻不会自动统一调色板，也不会修复模型生成的软边、形变或首尾接缝。

本地完整验证脚本：`node scripts/frame-animation-smoke.mjs <原型 PNG 路径> idle`。脚本新建含六种动作草稿的画布，用本地 MiniMax H3 生成所选动作，再导出 128 px 透明 PNG、图集和 ZIP。结果记录在 `output/frame-animation-smoke/run.json`，已有记录时使用 `node scripts/frame-animation-smoke.mjs --resume` 读取同一任务，避免重复生成；加 `--reexport` 可用同一视频重新导出。

“正常视频”使用原参考图和动作描述，保留场景背景，适合常规镜头。“帧动画视频”用于后续导出透明序列帧：提交前将首尾参考图的均匀底色剔除，再统一铺成纯品红或纯绿，并加入全程固定底色、亮度、镜头和画幅、无投影、无渐变和背景反光、主体完整不出框的约束。自动底色优先品红；任一参考帧主体含品红时，两帧都改用绿色，也可手动选择。主体与所选底色冲突时须更换底色或调整素材。

参考图需有真实透明通道或均匀纯色底，复杂背景应先在素材工坊处理。参考帧四周不足 4% 留空时，两帧使用一致的缩小留边处理；只修改送入模型的副本，保留原图。视频模型仍可能偏离底色约束，因此新生成的帧动画视频会逐帧识别实际边界底色、净化主体色边，并统一铺回所选底色。实际底色明显偏离约定颜色时，保护黑色描边包围的角色内部，避免黄色背景误删橙色鸭嘴、粉色背景误删盔甲；白色特效闭环不会保护里面的背景。处理保留尺寸、帧率及音频，并保存带半透明 Alpha 的无损母版；无法可靠区分底色或主体为空时报告失败，保留模型原文件。固定底色仅适合纯色背景，不代替人物语义分割或动作修复。

当前完整链路是：准备原型与首尾帧 → 填写动作阶段或选择模板 → 排队生成 → 固定底色与保护主体内部 → 保存透明母版 → 采样与缩放 → 导出 PNG / WebP、图集和 ZIP → 自动关联画布。动作模板、参考图校验、底色处理、透明持久化和导出已接通。当前动作描述仍以提示词约束模型；动作时序、角色与武器形变、循环首尾接缝、不合格结果自动重生成尚未形成自动验收。导出完成或透明帧数量正确不代表画面质量合格，交付前需要在深浅底逐帧检查完整动作。

“净化色边”同时清理独立的微小残留，以及贴在深色轮廓上的小块浅色压缩振铃。阈值按原视频分辨率缩放，黑色描边包围的内部高光、较大的光效和长条剑光保留；清理只移除判断为杂点的像素，不把剩余 Alpha 压成硬边，也不整体收缩轮廓。已有真实透明通道的输入直接保留，不重复清理。处理记录保存移除的像素和小块数量，逐帧视觉验收仍然必要。

视频母版处理会按原视频分辨率闭合深色描边的细小缺口，防止单个压缩像素打开整个头盔内部。连续帧校验使用前后两帧：仅在实际背景色近似不变、当前原始 RGB 与两侧变化都不超过 16、两侧 Alpha 接近且当前突变至少 16 时纠正孤立跳变。同时检查恢复颜色的孤立跳变，按预乘 RGB 衡量可见变化，原始画面自身的颜色变化保留。恢复不透明内部时读取当前帧自身的颜色，半透明部分保留分数 Alpha；快速运动、单调淡出、明显颜色变化的剑光和背景切换直接通过，不进行全局时域模糊。首尾帧无需复制或补帧，原帧数与音频时长保持一致。记录包含连续帧纠正的像素数。

描边闭合新增的内部区域若接近实际底色，须同时匹配首帧不透明角色的颜色，才会作为主体保留；这样可保护黄底上相近的鸭嘴，同时剔除手臂和披风间被闭合圈住的绿底。首帧颜色表只作背景相似像素的支持证据，不统一或重绘角色调色板。

首次默认正常视频，以后记住创建面板的用途选择；片段检查中的重生成单独选择用途，默认继承该片段类型。新片段、项目和历史记录保存用途及实际底色，透明序列帧导出会预选对应底色。原有视频不会自动更换类型或背景。

## 端到端帧动画规范

本规范对应当前已实现的流程，整理日期为 2026-10-05。适用于固定镜头、单个角色、透明或均匀纯色参考图，优先逐个动作导出透明帧。原型设计、生图结果选择和动作质量验收由人工完成；视频生成、边界处理、帧导出和画布关联由程序执行。不能把任务“已完成”当作美术验收“已通过”。

```text
角色原型与动作要求 → 生图 → 参考图验收
                                ↓
帧动画用途 + 动作模板 → 排队生视频
                                ↓
原尺寸逐帧抠图 / 色边清理 / 相邻帧纠错 → 无损 RGBA 母版
                                ↓
动作与透明边界验收 → 裁切与采样 → RGBA 缩放 → PNG / WebP + 图集 + ZIP
                                ↓
自动关联画布 → 深浅底动态验收 → 交付
```

### 1. 原型与生图输入

每个角色先确定一张认可的基准图，记录角色名称、朝向、比例、主要配色、描边、服装、武器及持握方式。所有动作复用这张图；只有有意修改角色设计时才更换基准图。先确定目标帧尺寸和脚底基线，后续动作保持统一画幅与角色尺度；跳跃允许离开基线，落地应回到原位置。

生图可选择画布已有的 Codex / GPT 或本地 Qwen。需要全程本地运行时，选择本地 Qwen 并检查 ComfyUI 与模型就绪，准备方式见 [本地 Qwen 生图说明](qwen-images.md)。原型设计要求目前以描述和参考图传入，没有自动判断角色设计是否合格的环节。

可复用的原型提示词：

```text
为帧动画制作单个全身像素角色：[身份、朝向、服装、配色、装备和持握方式]。
角色处于清楚的待机姿态，四肢与装备可辨，描边连贯，保留像素块与阶梯轮廓。
固定画幅，角色完整，四周至少留 4% 空隙，并为预期挥剑或跳跃额外留空间。
背景为均匀纯品红 #FF00FF；如果主体使用品红，改用纯绿 #00FF00。
无地面、投影、渐变、背景纹理、文字、棋盘格和额外特效。
```

人工确认主体、装备、朝向、尺寸和轮廓之后，才能作为动画参考。真实透明 PNG 也可以直接使用；画出来的棋盘格不是真实透明。复杂背景、原图已有白边或破损描边，应先在素材工坊清理，避免把缺陷传入视频。

### 2. 动作任务与视频生成

在新建片段中选择“帧动画视频”，或选择六种基础动作模板。每个片段描述一个动作，写明“起势 / 蓄力 → 执行 → 收势 / 恢复”，以及脚部移动、朝向、武器轨迹和是否循环。单次攻击默认不循环；待机、走路、跑步需要检查首尾接缝，勾选循环只改变播放方式。

例如前向突刺：保持基准图朝向和装备，前四分之一时间收剑蓄力，中段沿面对方向直线刺出，随后收回并恢复待机；脚底位置基本固定，只执行一次，不新增武器、目标或特效。若需要剑光，明确其颜色、范围、出现与消失阶段，并预留完整运动空间；保持主体颜色与底色可区分。

程序校验首尾参考图、选择两帧共用的品红或绿底，必要时一致缩小留边，并追加固定镜头、固定底色和不出框的约束。送入模型的副本可调整，原参考图保留。多个任务读取 ComfyUI 的实际队列依次执行；右上角只显示尚未完成的任务，失败状态需要处理。

边界处理随任务自动执行，不等待人工确认；在帧导出前先看完整视频：动作是否符合描述，头部、手脚、剑盾是否完整，主体是否出框，是否出现多余特效。提示词不能保证模型每次遵守；动作或角色形变不合格时，应修改描述或参考图后重新生成视频。

### 3. 边界稳定与透明母版

帧动画用途的生成视频采用以下处理顺序：

1. 保留模型原 MP4，在原尺寸、原帧率逐帧识别实际边界底色，处理模型造成的背景漂移。
2. 保护深色描边包围的主体内部，闭合细小缺口；新增封闭区域若与底色接近，还需首帧主体颜色支持，避免保留手臂或披风间的背景。
3. 使用邻近可信前景恢复混合边缘的 RGB 与分数 Alpha，清理微小独立杂点和贴轮廓的浅色残留，同时保留内部高光与较大的半透明光效。
4. 比较前后相邻帧，仅纠正原始颜色近似不变时的孤立透明跳变；真实移动和明显变化的特效不做全局模糊。
5. 保存 FFV1 无损 RGBA 母版，再由相同 Alpha 合成固定底色 MP4。单片段透明预览和导出读取母版，避免从 H.264 再抠一次。

当前处理版本为 `VIDEO_BACKGROUND_VERSION = 17`，权威值在 `server/video-background.mjs`。固定底色母版参数为容差 55、过渡 8、净化色边开启、收缩 0、硬边透明关闭。处理失败保留原文件并报告错误；缓存版本过旧时从原视频重新处理。规则适用于纯色背景和当前角色轮廓条件，复杂场景需要其他分割流程。

封闭背景区域与实际底色相近时，无论描边原本完整还是经过闭合，都需首帧角色颜色支持才会保留。拖尾淡出或背景变浅时，可沿用前面视频帧实际观察到的特效颜色，恢复低对比的分数 Alpha；近似底色的压缩噪声仍剔除。图集直接复制各帧的 RGBA 字节，避免透明底合成引入 RGB 舍入误差。

首帧颜色支持从不透明核心采集，排除压缩色边；首帧本身也用该证据再处理一次。经过参考图校验的所选底色须不出现在主体中，颜色支持的扩展范围也排除该底色的色相。背景变浅后，仍可识别原选定底色留下、且未经角色颜色支持的色点。可信颜色拟合得到的 Alpha 不再重复乘以容差过渡，避免特效淡出跨越抠色阈值时缺块。仅对角色调色板之外的彩色半透明特效，检查小范围内原始颜色接近的多数邻点，以修复压缩造成的小孔；不扩张角色轮廓、不填补真实背景缝隙、不改变不透明像素。连续帧校验向前保留已纠正的透明结果，同时以后一个未纠正帧作为支持证据，避免交替闪点只被前后翻转；固定底色 MP4 的不透明合成结果不进入透明校验。处理记录保存残色移除量和特效局部纠正量。

浅粉或白色底上的轮廓亮点另作局部检查：先清除原有细碎残片，再处理接触透明或低覆盖边界、邻近真实深色描边的浅色像素，以同帧附近已移除背景的颜色拟合描边颜色和覆盖率。拟合通过后保留半透明暗边，避免轮廓闭合和灰白色角色颜色表误保留不透明白点。最多检查两层细碎边界，每层使用独立快照，不按扫描顺序向主体传播；封闭内部高光、真实白色闪光和已恢复的彩色特效保留。此处理在原视频尺寸上进行，随后缩小 RGBA；不改变抽帧率，记录 `recoveredPaleContourPixels`。

### 4. 帧动画导出约定

| 设置 | 当前流程约定 |
| --- | --- |
| 范围 | 优先单片段；当前首尾帧包含尾帧，裁切和速度按实际片段生效 |
| 帧率 | 待机可用 8 fps，其他基础动作先用 12 fps；动作过快时提高帧率后重新验收 |
| 尺寸与缩放 | 当前五套基准为 128 px 最长边、最近邻；根据项目需求手动选择 64 / 128 等尺寸 |
| 透明 | 开启剔除背景与净化色边，默认收缩 0、硬边透明关闭，保留剑光等分数 Alpha |
| 画幅与对齐 | 所有帧尺寸相同，不逐帧裁边或重新居中，保持基准位置 |
| 包内容 | `frames/`、`sheets/`、`animation.json`、`preview.html`，使用真实 RGBA 与 straight Alpha |
| 画布关联 | 导出完成后按来源视频与覆盖范围关联片段，活动画布定期刷新读取最新可用结果 |

128 px 最近邻是当前验证流程的约定，通用导出窗口仍默认 512 px、平滑缩放，需要手动选择像素参数。通用抠色输入默认容差 12、过渡 4；生成视频的无损母版已经使用上述 55 / 8 参数处理，导出时保留其 Alpha，不再次执行普通抠色。

只有明确需要完全不透明的像素硬边、且接受柔光损失时才开启“硬边透明”；不能用整体收缩或阈值化代替杂边排查。单片段的母版保留链路已验证；整条时间线目前先按导出尺寸合成再统一抠色，尚未改为逐片段 RGBA 母版合成，带复杂特效时应分别导出并验收。

### 5. 验收与返工

交付检查应覆盖原视频全部帧和最终采样帧。仅检查导出的低帧率图片可能漏掉原视频中的单帧故障。

| 检查阶段 | 通过条件 | 未通过时返回 |
| --- | --- | --- |
| 基准图 | 角色设计、朝向与装备认可，主体完整，底色可分离，描边干净 | 原型或生图；已有背景问题先到素材工坊 |
| 原视频 | 动作清楚，装备不变形，不出框，循环动作首尾可衔接 | 动作描述或视频生成 |
| 透明边界 | 深底、白底、棋盘格下正常播放和慢放，周身无明显闪动白点、底色杂边或内部破洞，光效出现与消失自然 | 从原视频重做边界处理；源图已有缺陷则回到参考图 |
| 导出与回填 | 帧率、尺寸、顺序、循环标记正确，图集与逐帧图一致，画布关联到本次可用导出 | 导出参数或关联检查，无需重新生成视频 |

重点检查攻击峰值、剑光首次出现与消失、快速挥动、收势和循环接缝。统计值用于定位故障，仍需动态观看判断视觉质量。原参考图、模型原视频和导出记录保留，边界算法升级后使用同一源视频重处理，便于比较。

### 6. 已验证范围与尚未自动化的部分

鸭嘴骑士五套攻击动作已实际生成视频并更新到原画布：横向斩击、举剑下劈、前向突刺、盾牌撞击、原地回旋斩。该批次原视频为 640×640、24 fps，每套 73 帧；最终为 128×128、12 fps，每套 37 帧，共 185 帧。边界 v13 对全部 365 个原视频帧进行了检测，近似静止源像素的孤立 Alpha 跳变从 22615 降到 48，约减少 99.8%。这是特定批次的透明跳变指标，不是所有杂边的消除率，也不是其他角色的质量保证。

## 保存与导出

帧动画生成的默认交付位置是用户当前选中的角色画布。完成后应直接显示可播放的动画节点，并保留动作检查、透明帧、图集和下载；延续角色时沿用已有绘画页面与视频画布，不需要再次提醒回填。目标画布确实不明确时才询问。交付前必须检查用户正在看的标签页已同步，并让新节点位于可见范围。

活动视频画布每 3 秒读取最新项目，自动同步其他页面或工作流新增的片段，并把新节点纳入显示范围。本页的独立节点编辑与新片段合并，本页视角保留；同一字段的竞争修改或已修改片段的删除仍保留本地内容并拒绝覆盖。同步读取与自动保存串行处理，旧读取不会回退刚保存的内容。

顶部“画布”下拉框可以切换视频画布，“新建画布”创建独立的空画布，“重命名画布”修改名称。每个画布分别保存草稿与完成片段、关键帧图片引用、节点位置和尺寸、多轨时间线、裁剪范围、速度、音量、显隐、锁定、首尾帧标记、提示词与用途、画幅、选中片段、画布平移和缩放。关键帧副本保存在 `canvas/video-reference-images/`；导入视频信息保存在 `canvas/video-assets.json`，可跨画布复用。编辑后自动保存，也可点击“保存画布”；切换前会等待当前保存完成。保存失败时保留当前画布并提示原因，同一画布在另一页面更新时会拒绝覆盖。

原项目作为“默认画布”继续保存到 `canvas/video-project.json`，新画布保存在 `canvas/video-canvases/<画布 ID>.json`。重新打开工坊会恢复上次选中的画布。MP4 和序列帧导出使用当前画布，序列帧 JSON 记录来源画布。导入素材、生成视频副本和导出结果分别保存在 `canvas/video-assets/`、`canvas/video-generated/`、`canvas/video-exports/`；任务和导出记录保存在相应 JSON 文件中。`canvas/video-job-options.json` 保存生成用途与底色，供历史记录恢复类型。

生成完成的视频会复制到项目目录，因此 ComfyUI 重启或任务历史清空后，已保存的视频仍可预览、取帧和导出。帧动画视频分别保存 `<任务 ID>.mp4` 模型原文件、`<任务 ID>.background.mp4` 固定底色版本、`.background.alpha.mkv` 无损 RGBA 母版及 `.background.json` 处理记录。视频播放使用固定底色 MP4；单片段透明帧预览和导出直接读取 FFV1 母版，保留半透明信息，不从压缩 MP4 重新抠图。记录与母版匹配时重启后直接复用；旧版缓存从原始视频重新处理。运行数据已被 Git 忽略，迁移机器时需要单独备份。

导出完成后可下载 MP4。浏览器支持文件保存窗口时，也可点击“选择保存位置…”指定路径；否则使用浏览器默认下载位置。

序列帧导出下载为 ZIP，包含 `frames/` 中从 `frame-000000` 起顺序编号的逐帧图片、`sheets/` 中的精灵图集，以及 `animation.json` 中的帧率、循环标记、背景剔除参数、每帧文件和图集矩形。图集最大 4096×4096，超过容量时自动分页；坐标原点为左上角。单次最多 1200 帧，总像素量最多 256 Mi 像素，超出时需降低帧率、分辨率或裁短片段。图片保持宽高比，不放大小尺寸素材。

背景剔除复用素材工坊的颜色处理，适合均匀纯色背景，不是人物语义分割。自动背景色固定为首帧检测值，所有帧使用同一组参数；整条时间线也使用统一背景色。输出 PNG / WebP 和图集保留真实 RGBA 透明通道与非预乘 alpha，棋盘格只用于预览。所有帧保持相同尺寸与对齐，不单独裁边，避免播放抖动。已有真实透明边界的帧保留原透明度；关闭背景剔除则保留原视频背景。全部帧被移除时会提示调整参数，没有剔除任何区域时会显示警告。

单片段先在原尺寸（最长边最多 2048 px）剔除背景、净化色边，再缩小 RGBA，减少缩图时混入底色。抠图处理累计最多 512 Mi 像素；时间线先按导出尺寸合成，再剔除统一背景。默认“净化色边”用邻近的不透明主体或特效颜色拟合混合边缘，复用素材工坊的 RGB 反混合与平滑 Alpha 过渡；弱光效使用可信的前景颜色，避免把压缩噪声放大为彩边。对品红、绿色等底色的宽光晕向外搜索，角色的描边与深色衣甲会阻止搜索进入内部；已判定为背景的像素不会重新变成光晕，避免复活模型绘制的假棋盘格。固定底色时保留分数 Alpha 母版，再按实际透明度合成 MP4。只有导出时明确开启“硬边透明”才压成 0/255，默认保留柔光半透明。“边缘收缩”可选 0–3 个处理像素，默认 0 保留羽毛和细描边，残边可先尝试 1；真实透明母版保留原始边缘，不重新抠色或收缩。首帧预览可切换白底、深色底检查。

准备生图时沿用素材工坊的纯品红 `#FF00FF` 底；主体含品红则改用纯绿 `#00FF00`，主体不能使用所选底色。背景须均匀，无渐变、纹理、棋盘格、投影或底色反光，主体四周留至少 4% 空隙；生成视频时全程保持同一底色、亮度和画幅。设置窗口“生图底色规范”可复制这段提示词。深蓝底和深蓝服装、黑描边相近时，压缩视频已经混合的颜色无法完全还原，单靠增大容差会削掉角色细节。

单片段透明序列帧完成后自动关联到原片段，节点、左侧缩略图和时间线预览直接读取 PNG / WebP 图集，刷新或切换画布后仍可显示。从素材库把同一视频添加到另一画布或复制片段时，若已有帧动画覆盖新片段的完整裁切范围，会复用这些帧，无需重新生成或导出。右侧“透明帧动画”可播放、暂停、逐帧检查和下载；“查看原视频与首尾帧”保留原视频检查工具。替换视频来源后不会误用旧动画帧。

完成后也可解压后用浏览器打开 `preview.html`，点击画面可播放 / 暂停，拖动滑块逐帧检查，并切换透明棋盘、白色或深色背景检查残边。离线预览直接读取本地图片，无需启动服务。可将 `frames/` 的图片按文件名顺序载入引擎，以指定帧率播放；也可按 JSON 中的矩形切分图集。ZIP 内的 `README.txt` 说明坐标转换和 Unity 的透明导入设置。循环设置控制播放方式，不会自动修复首尾画面衔接。每帧时长为 `1 / fps`，总播放时长向上对齐到完整帧。导出任务在后台运行，关闭设置窗口后仍可从顶部提示下载；服务重启中断的任务需重新提交。

## 生成队列

右上角“生成队列”以单行显示任务名称、状态和等待位置；已完成任务自动隐藏，失败原因可悬停查看。任务按生成引擎的队列顺序串行执行。帧动画生成后显示“固定底色中”，底色处理也串行执行，处理完成才报告任务完成。等待位置包含其他本地生成任务，因此有其他工具占用时也会显示真实位置。可继续为其他片段提交任务，或 Ctrl / Shift 多选已准备首尾图、动作描述及可用模型的草稿，在右侧一次“加入队列”。批量提交按画布片段顺序进行，单个提交失败不会阻止后续片段提交。完成后视频自动填回原片段，点击队列中的任务可定位当前画布对应节点。队列连接中断时保留生成记录，并在连接恢复后自动更新。

## 验证

```bash
npm run test:video
npm run test:ui
npm run build
```

视频测试覆盖时间线和裁切参数、音频导出参数、模型工作流接线与宽高比，以及生成素材在 ComfyUI 历史消失后的持久化读取。安装 FFmpeg 时还会用实际测试视频验证序列帧裁切、首尾帧范围、透明处理、时间线层级与间隔、PNG / WebP 下载包和图集矩形；图集分页及透明帧与图集像素一致性单独验证。素材工坊测试覆盖共享算法的空心区域、柔边去污染和已有 alpha 保留。测试不执行耗时的模型推理，也不替代实际画面验收。
